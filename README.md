## 📱 **What is ZEON VIDEO CALL?**

**ZEON VIDEO CALL** is a professional **educational demonstration** platform that simulates a dating app video call feature. It showcases how modern dating apps work and helps security researchers understand:

- 🔐 How camera/microphone permissions work
- 📸 How media capture APIs function
- 🤖 How Telegram bots integrate with web apps
- 📊 How to track user interactions safely

> **⚠️ NOTICE:** This is a SIMULATION for educational purposes. No actual dating service is provided.
